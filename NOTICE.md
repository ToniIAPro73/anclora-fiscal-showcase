# Portfolio notice

This repository presents a reduced case study of Anclora Fiscal.

The operational source code is maintained separately and is not distributed
through this public repository.

The public material intentionally excludes:

- production source code;
- Shopify and Amazon KDP connectors;
- fiscal calculation rules;
- invoicing implementation;
- database schemas and migrations;
- VERI*FACTU generation and submission logic;
- authentication implementation;
- infrastructure and deployment configuration;
- real commercial, customer or fiscal information.

All examples and diagrams are conceptual and intended solely to demonstrate
software architecture and product-development experience.
